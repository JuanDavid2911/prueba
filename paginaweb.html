Comandos más Necesarios 📜

📢 Estos son los comandos más necesarios que tienes que aprender si o si para no tener problemas a la hora de usar el bot

  • 📌/Balance = Con este comandos miras tu Balance en general, te muestra tu cash, lo que tienes en el banco y el total de todo
  • 📌/withdraw = Con este comando puedes retirar dinero de tu banco
  • 📌/deposit = Con este comando puedes depositar dinero en tu banco
  • 📌/collect-income = Con este comando puedes recoger tus ingresos, sirve para los roles de niveles ya que te dan una cantidad de dinero cada cierto tiempo
  • 📌/work = Con este comando puedes trabajar y ganar dinero en caso de que pierdas todo
  • 📌/rob = Con este comando puedes robar dinero a otros usuarios (Tener encuenta que si tu tienes mas dinero que la otra persona sales perdiendo)
  • 📌/crime = Con este comando puedes cometer crimenes y ganar dinero, pero también arriesgas perderlo
  • 📌/give-money = Con este comando puedes dar dinero a otros usuarios

📢 Para usar mejor los Comandos si puedes robar o depositar rapido, puedes usar "," y pones luego lo que quieres hacer tipo: ,dep all o ,rob @usuario
